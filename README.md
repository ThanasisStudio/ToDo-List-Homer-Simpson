## English Version

An interactive, responsive, and bilingual To-Do List web application inspired by the iconic Homer Simpson notepad meme from *The Simpsons*.

![Preview](<img width="1080" height="936" alt="image" src="https://github.com/user-attachments/assets/d93c7f25-7e61-43d0-8cf2-f4b333442839" />) *(Optional: replace with your project screenshot)*

### ✨ Features
- **🎨 Iconic Simpson Style:** Living room theme, interactive TV, yellow hands holding the notepad.
- **🍩 Donut Checkboxes:** Check off tasks by biting a pink frosted donut!
- **🌐 Bilingual Support:** Instant toggle between English and Russian.
- **📱 Fully Responsive:** Works smoothly on desktops, tablets, and smartphones.
- **🔊 SFX & Audio:** Built-in Web Audio API sound effects and Homer's iconic quotes ("D'oh!", "Woo-hoo!").
- **🎉 Interactive Minigame:** Donut rain explosion with a counter.
- **💾 Auto-Save:** Local storage support for saving your tasks.

## Русская версия

Интерактивное веб-приложение списка дел в стиле легендарного мема с Гомером Симпсоном из «Симпсонов».

### ✨ Особенности
- **🎨 Стиль Симпсонов:** Гостиная, интерактивный телевизор, желтые руки Гомера с блокнотом.
- **🍩 Пончики-чекбоксы:** Отмечайте сделанные дела, "надкусывая" розовая пончик!
- **🌐 Двуязычность:** Мгновенное переключение между русским и английским языками.
- **📱 Полный адаптив:** Удобно пользоваться на ПК, планшетах и смартфонах.
- **🔊 Звуки и фразы:** Звуковые эффекты через Web Audio API и фирменные цитаты Гомера ("D'oh!", "Woo-hoo!").
- **🎉 Мини-игра:** Салют из пончиков с счетчиком съеденного.
- **💾 Сохранение:** Автоматическое сохранение ваших дел в памяти браузера.
